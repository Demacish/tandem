1 Hemmanätverk eller extern VPN?
expand_more
Om din Tandoor bara körs lokalt i hemmet måste din telefon vara kopplad till samma WiFi. Är du på språng behöver du WireGuard, Tailscale eller en omvänd proxy.
2 Krävs portnummer?
expand_more
Många Docker-installationer kräver specifik port efter adressen. Testa att skriva t.ex. https://192.168.1.50:8080 eller liknande port din server lyssnar på.
