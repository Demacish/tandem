Inofficiell klient för Tandoor

Tandem är ett fristående projekt med öppen källkod och är varken officiellt kopplat till, sponsrat eller godkänt av Tandoor Recipes eller dess grundare. Tandem ansluter till din självhostade Tandoor-server via dess öppna REST API.

Juridik & Dataskydd

All data lagras lokalt på din enhet eller krypterat på din egen angivna server. Ingen data delas med oss, externa molntjänster eller annonsnätverk. Dina recept och inköpslistor förblir 100% privata.

Tredjepartskomponenter: Apache License 2.0, MIT License samt Material Symbols (Apache 2.0).

Appen tillhandahålls i befintligt skick («as is»). Du ansvarar själv för drift, säkerhetskopior och driftmiljö för den Tandoor-instans som appen ansluter till.
